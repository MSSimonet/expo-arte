Conectar con Supabase

Para guardar las fotos reales en la nube desde cualquier celular y que se vean en GitHub Pages:

  1. Creá un proyecto gratuito en supabase.com.
  2. Abrí SQL Editor, pegá el contenido de supabase-setup.sql y ejecutalo.
  3. En Authentication → Users → Add user creá el email y contraseña docente.
  4. Copiá debajo tu Project URL y anon public key (de Project Settings → API).

Iniciar sesión docente
