Conectar con Supabase

Para guardar las fotos reales en la nube desde cualquier celular y que se vean en GitHub Pages:

  1. Creá un proyecto gratuito en supabase.com.
  2. Abrí SQL Editor, pegá el contenido de supabase-setup.sql y ejecutalo.
  3. Para cambiar el número de acceso docente si lo necesitás, editá la función de acceso en el SQL.
  4. Copiá debajo tu Project URL y Publishable / anon key (de Project Settings → API).

Ingreso docente

Ingresá el número de acceso docente para subir fotos, editar obras y gestionar los textos de la muestra.

Las fotos ahora se cargan desde la carpeta Obras/

Ya no se suben fotos desde este panel. Las obras salen de las carpetas Obras/1 a Obras/7 (una por grado) del proyecto, y se publican así:

  1. Copiá las fotos a la carpeta del grado (por ejemplo Obras/3 para 3° grado). Si querés mostrar autor y título, nombrá el archivo Autor - Título.jpg.
  2. En la terminal, dentro del proyecto, corré npm run obras.
  3. Subí los cambios a GitHub (assets/obras y obras.json). En un par de minutos las fotos están en la muestra.

Desde acá seguís pudiendo editar los textos de cada sala y moderar los mensajes de las familias.
